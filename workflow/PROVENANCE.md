# Provenance

The initial `0.1.0` package was extracted from the Signapse repository workflow on 2026-09-18 and generalized for reuse. The current collection maintains the following execution skills and their bundled resources:

- `agent-execution-policy`, `setup-workflow`, `implement`, `tdd`, `code-review`, `diagnosing-bugs`, `resolving-merge-conflicts`, and `codebase-design`

Planning and requirement skills extracted in earlier versions are maintained by the planning repository and are no longer distributed here.
